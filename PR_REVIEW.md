# Marketplace entry review checklist

- [ ] The source is publicly accessible and the license allows redistribution (MIT/Apache-2.0/CC-BY and similar), with the LICENSE and a source link kept in the repository.
- [ ] The artifact sha256 matches the Release file and the size is reasonable (plugins ≤ 50MB, skills ≤ 20MB).
- [ ] Plugins: the Release tag and asset name follow the convention (`plugins-YYYYMMDD`, with a `-2` suffix for a second release on the same day; asset name `<last id segment>-<version>.ddp`).
- [ ] Plugins: `entry.version`, `plugin.version` and the version in the asset file name all match.
- [ ] Plugins: the publisher signature is valid (`META-INF/plugin-signature.json`), `plugin.publisherKeyId` matches `^ed25519:[0-9a-f]{64}$` and equals the `keyId` in the signature.
- [ ] Plugins: `plugin.apiLevel` is 6; `plugin.minHostVersion` is at least 1.0.4 and not higher than the current host version.
- [ ] Plugins: `plugin.publisherName` is optional; it is the publisher display name and must belong to the same publisher as the signature `publisherKeyId`; when missing, the client falls back to the first 12 characters of the keyId.
- [ ] Plugins: `plugin.requiredAccess` truthfully states the access tier the plugin needs (`normal`/`adb`/`root`), and plugins that need Root explain why.
- [ ] Plugins: `plugin.previews` (if present) are 1–6 HTTPS portrait images (9:20) that match the plugin.
- [ ] Skills: the zip contains a single skill directory (with SKILL.md) and nothing out of scope beyond the binaries and scripts it needs.
- [ ] MCP: only remote HTTP endpoints are accepted — no local command/args/env; no collection of user credentials; `auth` and `authHint` describe the authorization method clearly.
- [ ] Category: `category` must be one of office/content/dev/study/research/business/design/life and must match the entry's purpose.
- [ ] Copy: `name`/`summary`/`description`/`tags` all have `zh` and `en`, the English reads naturally, with no developer notes or internal links; each language has 2–4 tags, without stacking synonyms.
- [ ] Icon: a PNG of ≤128KB with a traceable source (brand icons only identify their source); the `?v=` in the registry is generated by `publish.mjs`, and a mismatch with the file content hash means the registry was not regenerated.
